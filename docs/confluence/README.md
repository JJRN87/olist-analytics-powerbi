## Cómo leer la documentación

Las páginas se escribieron durante el desarrollo. Algunas capturas y referencias a tareas pendientes reflejan el estado del proyecto en ese momento. La revisión del sprint y la retrospectiva recogen el cierre de la primera versión.

Los PDF conservan su contenido original de Confluence; he simplificado los nombres de archivo para que los enlaces del repositorio sean estables. Los enlaces internos a los espacios privados de Jira o Confluence pueden pedir acceso, pero los documentos de este índice están incluidos en el repositorio.
